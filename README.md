# Milfor Eventos · Encuentra tu mesa

Página estática para que los invitados encuentren su mesa escaneando un código QR.

- Editar los datos del evento y el plano en `config.js`.
- La lista de invitados se publica codificada en `invitados.dat` (se genera con `preparar.py` desde un CSV `nombre,mesa,puesto,grupo,nota` que no se sube). Asientos y forma de cada mesa en `config.js`. Puesto 1 = silla del lado de la tarima, luego en sentido horario.

Publicada con GitHub Pages: https://milfor2026.github.io/milfor-mesas/
